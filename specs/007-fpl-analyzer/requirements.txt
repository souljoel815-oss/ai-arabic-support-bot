# ─── Note on Understat (xG/xA features) ────────────────────────────────────
# The `understat` package on PyPI hard-pins aiohttp==3.8.3, which has no
# wheel for Python 3.14. We hand-roll a minimal scraper inside fpl/api.py
# (`fetch_understat_optional`) that hits the public Understat HTML page
# and parses the embedded `playersData` JSON. On any failure (HTTP error,
# schema change, parse error) the analyzer reports `understat:
# unavailable` in the Run Status / Diagnostics panel and proceeds without
# xG/xA features (~5-8% MAE penalty per spec.md SC-004). Use the
# `--no-understat` CLI flag (or sidebar toggle) to skip the source
# entirely.
