# Tax-Inspection Bundle — Public Format Specification (placeholder)

**Status**: Stage 1 placeholder. Full content authored in Stage 15 (T250).

This file will become the public-facing format specification handed to Egyptian tax inspectors who receive a bundle generated by EgyptTax (US9 / FR-048). Scope (per [tasks.md](../specs/008-egypt-tax-accounting/tasks.md) T250):

- Archive structure (ZIP layout): `MANIFEST.sha256`, `verify-bundle.ps1`, registers/, attachments/, audit-trail/.
- `MANIFEST.sha256` schema: derived from [contracts/inspection-bundle-manifest.schema.json](../specs/008-egypt-tax-accounting/contracts/inspection-bundle-manifest.schema.json), human-readable explanation of every field.
- Verifier script usage:
  ```powershell
  PS> .\verify-bundle.ps1 -ArchivePath .\EgyptTax-Bundle-2026-Q1.zip
  ```
  Returns `valid`, `tampered`, or `manifest-missing`.
- Audit-trail extract format: streamed JSONL of audit-log entries per [contracts/audit-chain-verifier.md](../specs/008-egypt-tax-accounting/contracts/audit-chain-verifier.md), with the chain segment for the period.
- Cross-verification — how an inspector can independently re-hash any included document against its `MANIFEST.sha256` entry without trusting the company's running application.
- Legal positioning — this bundle is a self-contained evidence pack; it does not replace any regulator-mandated filing artifact, it complements one.

Until Stage 15, [contracts/inspection-bundle-manifest.schema.json](../specs/008-egypt-tax-accounting/contracts/inspection-bundle-manifest.schema.json) is the authoritative format reference.
