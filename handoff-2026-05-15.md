## §6. الـ gotchas — اقراها قبل أي tooling

1. **EF migrations** — لازم توقف الـ `dotnet run` قبل ما تعمل `dotnet ef migrations add` (الـ DLLs مقفولة). نفس الكلام مع أي build بيخلص بـ "Could not copy" errors — مش compile failures، الـ app شغال.

2. **Sidebar = 🔒 مقفولة** — متحاولش تدمج الـ ModuleSidebar + SubNavPanel في sidebar واحد. اتعمل marهتين قبل كده ورُجِع. الـ memory `feedback_appshell_sidebar_locked.md` بيشرح ليه.

3. **Razor / domain name-clash** — لما تعمل Razor page بنفس اسم aggregate (مثال: `DeferredRevenue.razor` vs `DeferredRevenue` entity)، الـ Blazor بيعمل partial class بـ shadow على الـ aggregate. الحل: اسم الـ Razor بالـ plural (`DeferredRevenues.razor`).

4. **DateOnly في EF** — متستخدمش `DateOnly.ToDateTime(...)` جوا الـ LINQ query (مش translatable). استخدم 3-step ordering: `OrderByDescending(HasValue).ThenByDescending(PostedAtUtc).ThenByDescending(DocumentDate)`.

5. **VatCategory.IsActive** — مفيش. متفلترش عليه.

6. **POS tiles legacy bridge** — لازم rule narrow `.appshell button:not([class])`. الـ rule الواسعة بتكسر `.pos-item-card` لـ inline-flex.

7. **E.8 partial wire-in** — الـ PaymentTermId بيتخزن على الـ invoice، بس الـ receipt-side discount routing لـ "4910 Discount Given" لسه. لما تعمل receipt voucher على فاتورة عليها term + ضمن discount window، الـ JE المفروض يفصل المبلغ المخصوم.
