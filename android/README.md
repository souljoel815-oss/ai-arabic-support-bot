# DaftarX Android — Phase 1 scaffold

**Feature**: [specs/009-android-app/](../specs/009-android-app/)
**Status**: Phase 1 (Setup) complete. Tasks T001–T016 of 128. Phase 2+ are scaffolded out in `tasks.md` and ready for the next session.

This folder hosts the Kotlin/Compose Android shell that wraps the DaftarX server in a native phone app (per [spec.md](../specs/009-android-app/spec.md)). It builds independently of the .NET solution at the repo root; the only intersection is the three new HTTP endpoints under `src/EgyptTax.Web/Pages/Api/Mobile/` (added in Phase 2 server-side tasks).

## First-time setup

### Prerequisites

- **JDK 17** (Temurin recommended); set `JAVA_HOME`.
- **Android Studio Koala (2024.1.1)** or newer — for the Compose preview, manifest merger, and emulator manager.
- **Android command-line tools** for CI (`sdkmanager`, `avdmanager`).

### Generate the Gradle wrapper (one time per fresh clone)

This skill scaffolded everything except the `gradle-wrapper.jar` binary (it's not a text file). Generate it once:

```pwsh
# From the android/ directory
gradle wrapper --gradle-version 8.10.2
```

Android Studio also does this automatically on first project sync. After that, every developer uses `./gradlew` (Unix) or `.\gradlew.bat` (Windows) — no system Gradle needed.

### Open in Android Studio

`File → Open → android/` (the directory containing `settings.gradle.kts`). Android Studio detects the catalog version + plugins automatically and runs Gradle sync.

### Add `google-services.json`

For Firebase Crashlytics + FCM to initialise, drop the vendor's `google-services.json` into `android/app/`. The file is gitignored — pull it from the vendor's password manager.

For initial dev (no Crashlytics, no push), the absence of the file makes `assembleDebug` warn but still build; FCM + Crashlytics no-op gracefully.

### Build

```pwsh
.\gradlew :app:assembleDebug          # debug APK
.\gradlew :app:testDebugUnitTest      # JUnit + Robolectric unit tests
.\gradlew :app:connectedDebugAndroidTest   # Espresso + Compose UI tests (needs emulator)
```
